# Текстовые тесты Start Point Studio v3

Дата: 10 ноября 2026 г. Исполнитель: один Codex последовательно в ролях. Метод: ручной проход инструкций с передачей версий пакета, внесением дефекта и проверкой условий выхода. Это не генерация, не независимая экспертиза и не фактчекинг по внешним источникам. API не использованы, расходы/попытки генерации во всех тестах — 0/0. Поддерживаемые длительности Veo не определялись.

## Общий вход и границы
Пакеты TEST-H-3, TEST-S-3, TEST-N-3 хранят direction, исходный бриф, реестр фактов, русские реплики, версию паспорта, результаты каждой роли, дефекты, расходы, следующий шаг и открытые решения. У всех: регламент 3.0 принят для системы; визуальные референсы, эталон голоса, параметры Veo, утверждённый бюджет и решения по эпизодам — TODO. G0 реально WAITING_FOR_PRODUCER. Для независимого исследования маршрута ниже используется только условная ветка «если G0/G1 были бы явно утверждены», не запись фиктивного одобрения. G2 реально не пройден, G3 без видео не выполнен, G4 разрешения нет.

## Общие проверки возврата и непрерывности
- Модельная ситуация, не реальное видео: план требует предмет в правой руке, предоставленный финальный скриншот показывает левую и другой угол камеры. Использовать видимые левую руку и фактическую камеру, не приписывать перекладывание. Скриншот не подтверждает звук. QA полного клипа остаётся открытым; следующий окончательный промт запрещён до приёмки G3.
- Повтор без диагноза → REVISION_REQUIRED к QA/Engineer. После диагноза нужны изменённый промт, польза/стоимость и остаток лимита; неизвестный тариф или превышение → WAITING_FOR_PRODUCER, без вызова сервиса.
- Изменение смысла сценария после G1 аннулирует зависимые раскадровку/промты и экспертные проверки, требует нового решения G1.
- Ни одна роль не просила повторно ввести весь исходный бриф: передавался пакет следующей версии. Запрашивались только реально отсутствующие поля.

**Итог:** три обязательных и один дополнительный ручной текстовый тест пройдены как проверки инструкций и обработки отказов. Реальные G0–G4 не утверждены; видео, голос, Veo, публикация и внешние источники не проверялись.
