# Start Point Studio v3

Используй навык при работе над «Точкой старта», от выбора темы до подготовки публикации. Он создаёт производственные материалы; наличие навыка не предоставляет доступ к Veo 3, TikTok или отдельным агентам.

## Обязательное чтение

1. [Полный регламент 3.0](references/reglament-v3.md), затем [оперативная bible](references/studio-bible.md).
2. [Паспорт тигра](references/tiger-character.md).
3. [Единый протокол](references/handoff-protocol.md).
4. [Showrunner](roles/showrunner.md) и [Technical Producer](roles/technical-producer.md).

## Маршрутизация

Showrunner определяет направление по запросу, фиксирует его в пакете и выбирает один маршрут:

| Направление | Маршрут | Основная экспертная проверка |
|---|---|---|
| История | [Historical](workflows/historical.md) | Historian |
| Наука | [Science](workflows/science.md) | Science Editor |
| Социальная психология | [Social](workflows/social.md) | Social Psychologist |
| Спорт | [Sports](workflows/sports.md) | Профильная проверка спортивных правил; Science Editor по научным утверждениям |

Для смешанных сюжетов оставляй основное направление и добавляй нужные экспертные проверки, не заменяя его социальным конфликтом. Перечень [ролей](references/role-routing.md) задаёт ответственность и адресатов возврата.

## Исполнение

Работай последовательно в ролях. Перед каждым переходом передавай полный [пакет](templates/production-packet.md), обновляя версию, статус и журнал решений. Не имитируй запуск 11 независимых агентов или реальное измерение аудитории. Для независимого исполнения нужен отдельный оркестратор; текущая версия — инструкции для одного исполнителя.

Начни с брифа и списка TODO. Неизвестное не заполняй догадками. Для текста допустимы явно помеченные варианты; визуальное производство блокируется до утверждения референсов. Сценарий проходит экспертов и продюсера до раскадровки. Промты пиши по [шаблону сцены](templates/veo-scene.md).

После каждой реальной генерации требуется просмотр результата и запись фактического финального кадра. Только затем можно окончательно подготовить и генерировать следующую сцену. План будущей сцены до этого — черновик. Не добавляй музыку без отдельного решения. Не обещай точное воспроизведение голоса одной текстовой инструкцией.

Если отсутствует обязательное решение продюсера — WAITING_FOR_PRODUCER. Если обнаружен дефект — REVISION_REQUIRED с конкретным адресатом. APPROVED означает прохождение указанной проверки и не разрешает автоматически генерацию или публикацию.

Регламент 3.0 принят по явному решению продюсера в запросе на интеграцию; DRAFT и метки происхождения в исходнике сохранены. Приоритет и оставшиеся решения — в bible. Отсутствие 2.0 не блокирует работу по 3.0.

Showrunner сопровождает каждый переход; Technical Producer контролирует расходы и попытки на всём маршруте. Исторический аналитик — по запросу; эксперт обязателен. Общий путь: Showrunner → Analyst / профильный эксперт → Screenwriter → повторная экспертиза → PRODUCER APPROVAL (G1) → Director → Veo 3 Prompt Engineer → Quality Control → TikTok Marketer. G2 закрывается до генерации, G3 — для каждого клипа, G4 — перед размещением.

Не сокращай требования Veo: перед промтом точная строка длительности, внутри посекундные действия, русская речь и lip sync, мимика/жесты, физика реквизита, свет, камера и композиция. Продолжение сохраняет фактическое состояние камеры и объектов; скриншот пользователя важнее планового кадра. Неподдерживаемая длительность требует пересборки плана, а не скрытого изменения.

Для первого запуска: [исторический сухой прогон](examples/historical-dry-run.md), затем [три теста v3](examples/text-tests-v3.md). [Отчёт интеграции](references/integration-report-v3.md) фиксирует конфликты и ограничения. Реальное производство ждёт материалов G0–G2, не повторного утверждения всего регламента.
