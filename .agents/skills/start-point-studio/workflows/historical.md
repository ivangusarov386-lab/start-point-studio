# Историческое направление

Применять [протокол передачи](../references/handoff-protocol.md); все переходы сопровождаются пакетом и статусом. Основное направление сохраняется до явного изменения продюсером.

1. **Выбор темы.** Showrunner → TikTok Analyst (по запросу; иначе сразу Historian): исторический вопрос, эпоха и самостоятельный исторический смысл. Предложить темы и гипотезу интереса без вымышленных метрик. Technical Producer предварительно оценивает ресурсы; неизвестные — TODO.
2. **Экспертная проверка.** Historian проверяет тему и реестр фактов. Проверить анахронизмы, предметы, даты и пределы реконструкции. Отделить условного тигра от исторических свидетельств. Другие эксперты подключаются при соответствующих утверждениях. REVISION_REQUIRED возвращается аналитику/автору; непроверенные обязательные сведения блокируют продвижение.
3. **Сценарий.** Screenwriter пишет русские реплики и действия. Historian повторно проверяет сценарий и все новые факты; Social Psychologist проверяет отношения, если они существенны. Technical Producer проверяет длительности и смету.
4. **Утверждение продюсером.** G0 закрывает бриф, формат, ограничения и референсы; G1 фиксирует экспертно проверенный сценарий, список фактов и решение продюсера по версии. Смета, хронометраж, раскадровка и первый промт утверждаются на G2. Без решения — WAITING_FOR_PRODUCER. Сухой прогон может остановиться здесь с текстовыми материалами.
5. **Раскадровка.** Director по утверждённому сценарию и паспорту задаёт движение, камеру, эмоции, звук и непрерывность. Historian проверяет фактические утверждения визуального ряда. Изменение смысла возвращает на G1.
6. **Промты.** Veo 3 Prompt Engineer заполняет [шаблон](../templates/veo-scene.md) на английском с русской речью. Technical Producer проверяет доступный режим, длительность и лимиты. G2: продюсер утверждает постановку, хронометраж, первый промт и смету до генерации. Платные вызовы не выполняются без отдельной авторизации и доступа.
7. **Фактические результаты.** После каждой разрешённой генерации Quality Controller просматривает и слушает клип; Historian проверяет новые/изменившиеся фактические детали. G3 закрывается только после приёмки и записи фактического финального кадра. Следующий промт окончательно готовится по этому кадру. Дефект → соответствующая роль; повтор → диагноз, изменённый промт, оценка пользы/затрат и Technical Producer, а при выходе за лимит — продюсер. Недоступный клип не считается проверенным.
8. **Подготовка публикации.** QA проверяет итоговый монтаж, речь, голос, факты и непрерывность; TikTok Marketer готовит русскую упаковку и субтитры. Technical Producer закрывает фактические расходы. G4: продюсер разрешает конкретную публикацию после проверки прав. Подготовка не равна размещению.

Завершение: пакет с версиями, фактическими результатами, решениями и открытыми TODO. APPROVED относится только к явно указанной проверке; дефекты дают REVISION_REQUIRED, решения человека — WAITING_FOR_PRODUCER.

## Обязательное сопровождение v3
Showrunner проверяет каждый переход по [регламенту 3.0](../references/reglament-v3.md). Technical Producer контролирует стоимость и число попыток на протяжении всех этапов; пакет переносит бриф, версии, факты, реплики, референсы, результат роли и ограничения без повторного ввода.

Перед каждым промтом указать «Длительность генерации в Veo 3: N секунд»; внутри английского промта — посекундные действия, русские реплики с lip sync, живая мимика, жесты, одежда/реквизит, свет и полная камера. При продолжении камера/композиция, физическое состояние объектов и хват сохраняются по фактическому финальному кадру; пользовательское изображение важнее плана. Без QA следующий окончательный промт не готовить. Музыки по умолчанию нет. SEO включает 3–5 тематических хештегов; публикация требует G4.
