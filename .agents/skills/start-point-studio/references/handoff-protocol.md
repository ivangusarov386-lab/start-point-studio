# Единый протокол передачи

Использовать [шаблон пакета](../templates/production-packet.md) для всех ролей. Пакет передаётся целиком либо как версия с точными ссылками на доступные артефакты; фраза «как обсуждали» недостаточна. Не удалять ограничения предыдущих ролей. Хранение: `production/<episode-id>/` в репозитории при запросе на выпуск; текущий навык не создаёт производство автоматически.

## Статусы
- APPROVED: указанная роль проверила конкретную версию на данном этапе; все обязательные условия этапа выполнены.
- REVISION_REQUIRED: есть дефект; обязательны ID, серьёзность, адресат, требуемое исправление и критерий повторной проверки.
- WAITING_FOR_PRODUCER: отсутствует обязательное решение или материал продюсера; зависимая работа остановлена, независимая текстовая подготовка допустима с TODO.

Различать статус отдельных артефактов и пакета. Пакет APPROVED только если текущие обязательные проверки APPROVED и необходимые решения продюсера присутствуют. При дефекте ставить REVISION_REQUIRED; после исправления при оставшемся решении — WAITING_FOR_PRODUCER. Не использовать APPROVED для всего выпуска по результатам одного шага.

## Передача и возврат
Автор указывает отправителя, получателя, этап, версии входов/выходов, ограничения и следующий шаг. Получатель проверяет наличие входов и полномочий до работы. Изменение утверждённого артефакта аннулирует зависимые проверки: перечислить затронутые материалы и повторить проверки, включая продюсера при изменении его решения.

## План и наблюдение
Запланированный финальный кадр находится в раскадровке. Фактический — только в QA после просмотра конкретного файла. Запись включает ID клипа/попытки, путь и версию, длительность, таймкод последнего декодируемого кадра, изображение кадра или доступную ссылку, описание состояния и отклонений, прослушанный звук. Если видео недоступно, не выдумывать наблюдения: QA не пройден, следующая генерация заблокирована.

Следующий промт ссылается на принятый клип и фактический кадр, описывает совпадающее начальное состояние. Если смена плана/места намеренная, Director документирует переход и сохраняемые признаки. Поддержку image/reference/extend проверять отдельно; текстовое описание кадра не выдавать за его техническую передачу модели.
