# Маршруты ролей

- [Showrunner](../roles/showrunner.md) — Координировать оригинальный сериал и сохранять выбранное направление.
- [TikTok Analyst](../roles/tiktok-analyst.md) — Оценить понятность темы и гипотезу интереса аудитории.
- [Social Psychologist](../roles/social-psychologist.md) — Обеспечить достоверные мотивы и социальные взаимодействия.
- [Historian](../roles/historian.md) — Проверять исторический контекст и отделять его от художественного вымысла.
- [Science Editor](../roles/science-editor.md) — Сохранять научную точность и корректность спортивных объяснений.
- [Screenwriter](../roles/screenwriter.md) — Создавать оригинальный драматургически ясный сценарий на русском.
- [Director](../roles/director.md) — Переводить сценарий в понятную визуальную последовательность.
- [Veo 3 Prompt Engineer](../roles/veo-prompt-engineer.md) — Создавать полные английские промты с русской речью.
- [Quality Controller](../roles/quality-controller.md) — Проверять реальные результаты относительно утверждённого пакета.
- [TikTok Marketer](../roles/tiktok-marketer.md) — Подготовить честную упаковку и публикационный пакет.
- [Technical Producer](../roles/technical-producer.md) — Контролировать ресурсы, стоимость и повторные генерации.

Общий порядок: Showrunner → TikTok Analyst → профильные эксперты → Screenwriter → повторная экспертиза → продюсер → Director → Technical Producer → Prompt Engineer → фактический результат → Quality Controller → TikTok Marketer → продюсер. Technical Producer участвует также при первом планировании и каждом повторе. Возврат адресуется владельцу дефектного артефакта; все зависимые материалы получают новую версию и повторную проверку.
