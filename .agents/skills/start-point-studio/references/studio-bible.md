## Продукт и драматургия (§1, §4)
Четыре равноправных направления: история, наука, социальная психология для подростков и взрослых, спорт. Не вытеснять историю, науку и спорт социальными историями. Единый TikTok-канал; каждый ролик понятен самостоятельно. Постоянный оригинальный антропоморфный стилизованный 3D-тигр; дополнительные постоянные персонажи отдельно утверждаются.

Короткие познавательные ролики обычно 30–60 секунд; длинные сюжетные — ориентировочно 3 минуты; экспериментальные эмоциональные — 60–90 секунд [ВОССТАНОВЛЕНО]. Это длительности роликов, не одной генерации. Точный хронометраж задаёт бриф. Правдивый хук в первые 1–3 секунды [ВОССТАНОВЛЕНО], интрига, развитие, полноценная развязка; действия предпочтительнее длинных объяснений. Не злоупотреблять «Ого», «Ничего себе», постоянным восторгом и обращением в камеру. Тигр может молчать, сомневаться, шутить и наблюдать.

## Экспертиза (§3, §5)
История — Historian; наука — Science Editor; социальные истории — Social Psychologist. Смешанные сюжеты добавляют экспертов к конкретным утверждениям, не меняя ведущий маршрут. Спорт — профильная проверка правил; Science Editor участвует при научных/физических утверждениях, Social Psychologist — при соответствующих отношениях, Historian — при историческом контексте.

Факты не искажать ради зрелищности. Реестр: ID, утверждение, источник и место, реально проверенное, дата, ограничения и статус. Не выдумывать ссылки и экспертные оценки. Исторические реконструкции и диалоги маркировать как вымысел. Научные схемы обозначать как визуализации, сохранять масштаб и физический смысл. Реальные места и объекты узнаваемы в согласованной 3D-стилистике; референсы не обязаны появляться фотографиями. Тигр — художественный проводник, не историческое свидетельство.

Социальный конфликт: мотивы обеих сторон, последствия, реалистичный шаг к разрешению. Нет универсальных диагнозов, карикатурных злодеев, магического примирения, обязательного счастливого финала и подмены профессиональной помощи.

## Персонаж и Veo (§6–7, §10)
Паспорт и утверждённые изображения определяют внешность; не придумывать канон. Сохранять полосы, пропорции, морду, мимику и манеру движения. Эпизодический костюм меганевры не переносить во все ролики. Оригинальный голос — дословный блок из [паспорта](tiger-character.md), подтверждение только прослушиванием.

Промт английский, реплики исключительно русские и точные, с синхронизацией губ. Перед каждым промтом — «Длительность генерации в Veo 3: N секунд»; внутри действия и речь разбиты по секундам. Длительность проверяется по доступному режиму, не предполагается. Описывать одежду, позы, реквизит, эмоции, живую мимику, жесты, окружение, свет, камеру, движения, звуки, ограничения и планируемый финальный кадр. Не сокращать обязательные требования. Нет фоновой музыки по умолчанию; атмосфера не мешает речи.

При продолжении сохранять физику объектов и хват, положение персонажей, взгляд, свет, перспективу, угол, кадрирование и позицию камеры по фактическому финальному кадру. Скриншот пользователя имеет приоритет над планом; не домысливать невидимые действия. Смена камеры — только отдельный явно согласованный переход Director, не скрытая смена при продолжении. Нет массовой генерации без промежуточного QA и бюджета.

## G0–G4 (§8)
| Точка | Обязательный результат | Условие остановки |
|---|---|---|
| G0 Бриф | Направление, тема, формат, ограничения, утверждённые референсы | Критические данные отсутствуют → WAITING_FOR_PRODUCER |
| G1 Сценарий | Экспертно проверенный сценарий, реестр фактов, явное решение продюсера по версии | Нет решения → WAITING_FOR_PRODUCER; дефект → REVISION_REQUIRED |
| G2 Раскадровка | Сцены, хронометраж, первый промт, параметры и смета; решение продюсера | Нет утверждения/лимита/доступа → WAITING_FOR_PRODUCER |
| G3 Генерация/QA | Реальный клип, просмотр/прослушивание, ошибки, принятый фактический финальный кадр | Дефект → REVISION_REQUIRED; нет видео → QA не выполнен, запрос результата; следующий промт заблокирован |
| G4 Публикация | Проверенный монтаж, SEO, описание, 3–5 хештегов, права и явное разрешение продюсера | Без разрешения не публиковать |

APPROVED относится к этапу и версии, не даёт автоматического разрешения на генерацию/публикацию. Technical Producer сопровождает весь процесс; каждый повтор требует диагноза, изменённого промта, оценки пользы/затрат и проверки лимита. Превышение лимита — только через продюсера. Showrunner ведёт каждый переход. Текстовый тест может моделировать переходы только с явной пометкой, не выдавая их за реальные утверждения.

## Публикации и данные (§11–12)
SEO: релевантные ключевые слова, честное описание, 3–5 тематических хештегов, без расчёта на #fyp/#viral. Первые 10–12 публикаций — проверка гипотез; 2–5 качественных публикаций в неделю при ресурсах — ориентир, не утверждённый график. Удержание, досмотры, повторы, репосты, сохранения, подписки — только реальные данные. Содержательные комментарии и узнавание опыта в социальных сюжетах — качественный сигнал, не замена количественных метрик [НОВОЕ / УТВЕРДИТЬ в источнике, принято текущим решением].

Разделять правила, роли/маршруты, утверждённые референсы, production-пакеты, версии, источники и QA. В публичный GitHub не помещать секреты, токены, персональные данные и материалы с ограниченными правами; места хранения и доступность согласовать. Наличие Skill в GitHub не устанавливает его автоматически в ChatGPT.
