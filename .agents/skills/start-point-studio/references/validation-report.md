# Проверка Start Point Studio v3

Дата: 10 ноября 2026 г. Аудит охватил AGENTS.md, SKILL.md, все 11 ролей, четыре workflows, references, templates, исторический пример и README. Приложенный DOCX прочитан полностью, включая таблицы; текстовых колонтитулов/сносок/комментариев не обнаружено. Исходник сохранён побайтно, текстовая копия проверяется против извлечённого текста.

Структурная проверка: frontmatter name/description реальным PyYAML-парсером (обнаруженное некавыченное двоеточие прежней версии исправлено через `>-`), существование относительных ссылок, 11 ролевых контрактов, четыре маршрута, G0–G4, точный голосовой блок, поля промта и пакета. Ручная проверка: приоритет 3.0 и решения продюсера, статусы, возвраты, отсутствие подмены направлений, непрерывность камеры/объектов, границы роли эксперта и полномочий человека.

Три обязательных текстовых теста history/social/science и дополнительный sports выполнены в [протоколе](../examples/text-tests-v3.md). Зафиксированы входы, версии, дефекты, исправления, условные переходы и реальные стоп-условия. Ни одно тестовое одобрение не подставлено в реальные G0–G4.

Итог выполненной автоматической проверки: PASS — 29 Markdown-файлов и их относительные ссылки; PyYAML frontmatter; 11 полных ролевых контрактов; четыре workflow и G0–G4; побайтовая сохранность DOCX/SHA-256 и полнота текстового извлечения; точный голосовой блок; обязательные поля сцен/пакета; наличие протоколов тестов и сохранность всех прежних файлов. `git diff --check` — без ошибок. Смысловые результаты тестов оценены вручную, наличие их разделов дополнительно проверено скриптом; это не автоматический тест реального видео.

Регистрация навыка в интерфейсе, реальные видео/звук, качество Veo, внешние исторические/научные источники и независимые агенты не проверялись. API не подключались, видео не генерировались, публикации не выполнялись. Для практической генерации нужны референсы, бриф, бюджет/режим и решения по G0–G2.

Ниже сохранён первоначальный отчёт как история v0.1. Его упоминание ожидаемого 2.0 описывает прошлое состояние и не является текущим блокирующим требованием; актуален регламент 3.0.

# Проверка версии 0.1

Дата: 2026-11-10. Область: документы навыка и текстовый маршрут; без API и внешних сервисов.

- SKILL.md: YAML frontmatter с name и description, имя соответствует каталогу; инструкции чтения и маршрутизации присутствуют. Регистрация в клиенте Codex отдельно не проверялась.
- Все 11 ролей имеют миссию, обязанности, входы, выходы, критерии качества и условия возврата.
- Четыре самостоятельных workflow содержат восемь этапов и контрольные точки G0–G4. Направления не подменяются социальным.
- Относительные Markdown-ссылки проверены на существование файлов.
- Проверены зависимости: эксперт → сценарий → повторная экспертиза → решение продюсера; раскадровка → промт → результат → QA → фактический кадр → следующий промт.
- Проверена семантика статусов: открытый дефект даёт пакету REVISION_REQUIRED; ожидаемое решение отдельно WAITING_FOR_PRODUCER. После закрытия дефекта пакет ожидает человека. APPROVED роли не разрешает публикацию.
- Исторический сухой прогон H-TEST-001 прослежен по инструкциям: сохраняет history, отмечает отсутствие периода и источников, возвращает задачу Showrunner, блокирует производство до G0/G1. Тестовая ситуация с руками явно обозначена вымышленной и не включена в канон.
- Внешность не придумана; регламент 2.0 не реконструирован; эталон голоса и остальные недостающие данные отмечены TODO. Голосовая инструкция в паспорте и шаблоне совпадает с предоставленной пользователем.
- В каждом шаблоне сцены обязательны длительность, движения, камера, персонажи, эмоции, русская речь, звуки и непрерывность. Музыки по умолчанию нет.

Это проверка структуры и ручной текстовый прогон, а не независимая историческая экспертиза, генерация Veo, проверка реального клипа или испытание мультиагентной инфраструктуры. Производственные контрольные точки в примере не пройдены. Полное соответствие регламенту 2.0 ожидает исходного документа.
