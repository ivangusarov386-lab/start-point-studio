# Правила проекта «Точка старта»

Для разработки мультсериала используй [start-point-studio](.agents/skills/start-point-studio/SKILL.md). Сначала прочитай SKILL.md, полный регламент 3.0, studio-bible, файл персонажа и протокол передачи; затем только нужный workflow и ролевые инструкции.

Роли — последовательные режимы работы Codex, а не уже запущенные независимые агенты. Showrunner ведёт пакет и передаёт его следующей роли. Не заявляй о независимой экспертизе, если её не было. Настоящие независимые агенты требуют доступного оркестратора, изолированных контекстов, управления доступом и журналирования; здесь такой инфраструктуры нет и создавать её без задачи не нужно.

Сохраняй четыре равноправных направления: история, наука, социальная психология, спорт. Не подменяй выбранное направление другим. Не выдумывай факты, утверждения продюсера, внешность тигра, результаты генераций, метрики TikTok или отсутствующие сведения регламента. Неизвестное отмечай TODO.

Продюсер — пользователь или явно назначенный им человек. APPROVED от роли не заменяет утверждение продюсером. На обязательной контрольной точке без явного решения ставь WAITING_FOR_PRODUCER. Не вызывай платные API и внешние сервисы в рамках подготовки навыка и тестов. Не публикуй материалы без отдельного явного разрешения.

Используй существующий checkout; не создавай worktree без запроса. Не меняй правила проекта молча. Все рабочие пакеты должны различать планы, источники, гипотезы и фактически просмотренные результаты.

## Нормативная база v3
Основной источник — [регламент 3.0](.agents/skills/start-point-studio/references/reglament-v3.md), утверждённый текущим решением продюсера, несмотря на DRAFT внутри исходного DOCX. Сначала прочитай его полностью; затем применяй bible и роли. Приоритет: последнее явное решение продюсера → актуальный утверждённый регламент → паспорт/референсы → сценарий/кадры → шаблоны. Маркировки происхождения правил сохранены. Регламент не утверждает отдельный эпизод или расходы. Не требуй 2.0 как условия запуска; при обнаружении сверить и эскалировать реальные конфликты.

Showrunner участвует в каждом переходе, Technical Producer контролирует затраты и попытки на всех этапах. Пакет передаётся полностью без повторного ввода брифа. Для истории аналитик по запросу; профильная экспертиза обязательна. Спортивные правила проверяются профильным специалистом/источником, научная роль подключается по содержанию. Продолжение сцены сохраняет физическое состояние, камеру и композицию фактического финального кадра; следующий окончательный промт — только после QA.
